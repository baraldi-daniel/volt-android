# VOLT: New York Uprising — protótipo Android

Protótipo 3D em Godot 4.4.1 com cidade procedural, combate, inimigos, 20 chefões sequenciais e controles de toque.

**Não é um jogo AAA nem um APK pronto.** O GitHub Actions tenta gerar o APK debug quando estes arquivos estão na raiz de um repositório GitHub. Esta versão não foi compilada/testada no Godot neste ambiente.

Para obter APK: envie o conteúdo deste ZIP para um repositório GitHub (preservando `.github/workflows/android.yml`), abra Actions > Gerar APK Android, execute e, se ficar verde, baixe o artefato `VOLT-Android-APK`.
